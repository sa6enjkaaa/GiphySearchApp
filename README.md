# GiphySearchApp

iOS test task implemented with Swift and SwiftUI.

## Features

- GIF search using the Giphy API
- Search debounce
- Animated GIF grid
- Pagination / load more
- GIF detail view
- Loading and error states
- Network availability handling
- Separate navigation routing
- Unit tests
- Portrait and landscape support

## Technologies

- Swift
- SwiftUI
- URLSession
- SDWebImageSwiftUI
- Network
- Swift Testing
